내 스마트폰 푸시 알림 설정

이 스마트폰 한 대를 채용공고 푸시 수신 기기로 등록합니다.

Firebase 프로젝트 설정을 입력한 후 등록 버튼을 눌러주세요.

  1. Firebase 프로젝트에 웹 앱을 등록합니다.
  2. Cloud Messaging에서 웹 푸시 인증서(VAPID 공개 키)를 발급합니다.
  3. 저장소의 firebase-config.js에 웹 앱 설정값과 VAPID 공개 키를 입력합니다.
  4. 이 페이지를 다시 열고 아래 등록 버튼을 누릅니다.
  5. 발급된 토큰을 GitHub 저장소 비밀값 FCM_DEVICE_TOKEN에 등록합니다.

Firebase 설정을 확인할 준비가 되었습니다.

보안 안내
기기 토큰은 공개하지 마세요. Firebase 서비스 계정 비공개 키는 웹사이트에 입력하지 않고 GitHub Actions 비밀값으로만 보관합니다.
